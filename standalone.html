1. FETCH CYCLE Phase 1 Specification
MAR ← PC, MDR ← Mem[MAR], IR ← MDR, PC ← PC + 1
  • 1. PC address copied to MAR
  • 2. Memory Read strobe pulses
  • 3. Opcode fetched into MDR
  • 4. MDR transferred to IR
  • 5. PC auto-increments to next instruction
2. DECODE CYCLE Phase 2 Specification
Control Unit interprets fetched opcode
  • 1. CU inspects opcode part of IR
  • 2. Identifies operation (LOAD / ADD / STORE)
  • 3. Decodes operand address (500, 600, 700)
3. EXECUTE CYCLE Phase 3 Specification
ALU arithmetic & RAM read/write execution
  • 1. MAR loaded with operand address
  • 2. Data transferred via MDR (3456, 1200)
  • 3. AC updated or target memory written (4656)
